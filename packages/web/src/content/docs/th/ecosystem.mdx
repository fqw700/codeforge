ชุดโครงการชุมชนที่สร้างขึ้นบน CodeForge

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ CodeForge ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-codeforge](https://github.com/awesome-codeforge/awesome-codeforge) และ [codeforge.cafe](https://codeforge.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
